# AulaConnect 

## Sobre o projeto

O AulaConnect é um sistema web de agendamento e gerenciamento de aulas, desenvolvido com o objetivo de facilitar a organização de professores e alunos.

A proposta é permitir que professores gerenciem seus alunos, organizem horários e acompanhem os agendamentos de suas aulas em um único sistema.

## Objetivo

Desenvolver uma aplicação que simplifique a gestão de aulas, tornando o processo de organização mais prático e eficiente.

## Tecnologias utilizadas

- Python
- FastAPI
- MySQL
- SQLAlchemy
- Git e GitHub

## Desenvolvimento

O projeto está sendo desenvolvido por etapas, começando pela estrutura do backend, conexão com o banco de dados e cadastro de usuários.

Futuramente, serão implementadas funcionalidades como autenticação, gerenciamento de perfis, agendamento de aulas e notificações.
